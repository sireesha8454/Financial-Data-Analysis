# Power BI Business Dashboard

This project contains an interactive Power BI report designed to analyze business performance and convert raw data into clear insights. The dashboard focuses on trends, comparisons, and key metrics that actually help decision-making — not just pretty charts.

##  Features

- Revenue and profit trends over time  
- Category and product-level comparisons  
- KPI tracking (growth, margins, variances)  
- Drill-downs for deeper exploration  
- Highlighted anomalies and outliers
